## 核心能力

### 1. 配置层
- 顶部「AI 设置」按钮（带 ● enabled 状态点）→ 抽屉面板
- 字段：开关 + Base URL + API Key + Model + 提示词目录
- 支持 OpenAI 兼容接口（DeepSeek / 通义 / Kimi 等）
- localStorage 持久化，apiKey 空时 enabled 强制 false
- 测试连接按钮（临时读 UI 值测试，不需先保存）

### 2. 调用层
- `callAI(messages, opts)` 封装 fetch，返回 `{ok, data, error}`
- 错误降级：401/429/网络失败 → toast 不阻断主功能
- `loadPrompt(name, vars)` 读 prompts/ + 注入 `{{var}}` 占位符，文件不存在用内置兜底
- `parseAIJSON(text)` strip ```json 围栏 + try/catch 兜底原文

### 3. 每步校验
- 每个 phase / artifact 旁加「AI 校验」按钮（CSS `body.ai-enabled` 控制显示）
- 点击 → 构造 dataSummary + loadPrompt("step-check") → callAI → 小卡片显示
- 结果：准确性 high/medium/low + 理由 + 可忽略标记 + 建议
- 自动写入记忆留存

### 4. 整体总结
- 阶段进度标题旁「AI 总结」按钮
- 点击 → 构造 fullData + loadPrompt("summary") → callAI → 总结卡片显示
- 结果：summary 文本 + gaps 缺口列表 + suggestions 改进建议
- 自动写入记忆留存（stepType=summary）

### 5. 提示词文件（prompts/）
| 文件 | 作用 |
|------|------|
| purpose.md | 目的：分析器做什么、AI 辅助角色 |
| rules.md | 规则：不臆测、给理由、标可忽略、中文 JSON |
| spec.md | 规范：每步校验 + 整体总结 JSON schema |
| step-check.md | 每步校验模板，占位符 stepType/stepId/dataSummary |
| summary.md | 整体总结模板，占位符 fullData |

用户可编辑这些文件调整 AI 行为，无需改代码。

### 6. 记忆留存
- localStorage key `pa_ai_memory_v1`，滚动保留最近 50 条
- 每条：id/ts/project/stepType/stepId/accuracy/reason/canIgnore/suggestion
- 导出 .md 按项目分组，可累积跨次参考
- 配置面板「导出记忆」/「清空记忆」按钮
