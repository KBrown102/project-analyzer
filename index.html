项目结构分析器

PROJECT ANALYZER

选一个项目文件夹，它按项目形态逐项检查 —— 你在做的是哪一类项目、走到哪一步了、离「能交付」还差什么。 不猜、不打分排名，只对着模板列缺口。

在线打开分析器 下载离线版（单文件 HTML）

文件不会被上传到任何地方·断网可用·零安装、零依赖

它能做什么

认出项目形态

内置 18 套模板 —— 游戏、前端工程、Electron 桌面、Python、DevOps、IaC、规则仓库…… 扫一遍目录结构就能判断属于哪一类，再用那一类的标准来衡量你。

列缺口，不是打分

按阶段和产物逐项对照，缺什么、该在哪一步补，配上 P0–P3 优先级和具体做法。做得好的地方也会单独列一份亮点清单。

对比前后两次

同一个目录分析两次，就能看出这段时间补的文档、加的测试有没有真的落到该落的位置。

AI 辅助（可选）

想让它替你判断和总结，就填一个 OpenAI 兼容的 API key（DeepSeek / 通义 / Kimi / 本地 Ollama 都行）。不填也能用，只是这部分能力关掉。

三种用法

在线版
点上面的「在线打开分析器」，选文件夹即可。适合快速看一眼，不用下载任何东西。
离线版
下载那个单文件 HTML，双击就在浏览器里跑。功能和在线版完全一样，断网可用，也不怕以后这个页面关掉。
Windows 独立版
要分析几万个文件的大目录时用这个。浏览器版超过 8000 个文件会明显变慢，独立版是原生遍历，深度 8 层 / 3 万文件封顶。打包脚本在仓库里。
